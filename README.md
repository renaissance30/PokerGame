# PokerGame - Five Card Stud Poker

一个基于 C 语言开发的控制台扑克牌游戏项目，实现了 Five Card Stud（五张牌梭哈）的基本游戏流程。

本项目是一个 C 语言课程实践项目，主要用于学习和实践结构体、指针、枚举、模块化编程、头文件管理以及多文件项目开发。

## 1. 项目简介

PokerGame 是一个基于标准 52 张扑克牌的控制台游戏。

玩家可以选择不同的游戏模式，系统会自动完成洗牌、发牌、手牌分析以及胜负判定。

### 游戏模式

目前支持以下三种模式：

- **单人模式（Single Player）**：玩家独自进行牌型练习，系统分析并展示当前手牌的牌型。
- **多人对战（Multiplayer）**：支持 2–6 名玩家参与游戏，玩家可以自定义姓名，系统自动比较所有玩家的牌型并确定胜者。
- **人机对战（Human vs Computer）**：玩家与计算机进行对战，由系统自动完成发牌和胜负判定。

## 3. 项目结构

项目采用模块化设计，将不同功能划分到独立的 `.c` 源文件和 `.h` 头文件中。

```text
PokerGame/
│
├── card.c / card.h          # 扑克牌基本数据结构
├── deck.c / deck.h          # 牌堆初始化、洗牌与抽牌
├── hand.c / hand.h          # 手牌管理
├── player.c / player.h      # 玩家信息与战绩管理
├── game.c / game.h          # 游戏状态与流程管理
├── evaluate.c / evaluate.h  # 手牌牌型识别
├── compare.c / compare.h    # 玩家牌型比较与胜者判定
├── io.c / io.h              # 输入输出处理
├── main.c                   # 程序入口
│
└── README.md                # 项目说明文档
```

## 5. 编译与运行

### 方法一：使用 Visual Studio

1. 使用 Visual Studio 打开项目解决方案文件（`.sln`）。
2. 选择合适的构建配置（Debug 或 Release）。
3. 点击「生成解决方案」。
4. 生成成功后，进入项目输出目录。
5. 运行 `PokerGame.exe`。

### 方法二：直接运行

如果已经获得编译好的 `PokerGame.exe`，可以直接双击运行。

## 6. 核心技术

本项目主要涉及以下 C 语言知识：

- **结构体（struct）**：用于组织扑克牌、牌堆、手牌、玩家和游戏状态等数据。
- **枚举（enum）**：用于定义扑克牌花色、点数以及游戏模式。
- **指针（pointer）**：用于在不同模块之间传递和修改数据。
- **模块化编程**：通过头文件和源文件划分功能模块，降低模块之间的耦合。
- **动态输入处理**：使用 `fgets()` 等函数处理用户输入。
- **随机数生成**：利用 `rand()` 和 `srand()` 实现洗牌。
- **排序与比较算法**：对手牌进行整理，并依据牌型和点数比较玩家之间的大小。
